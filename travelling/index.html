Travelling

Travelling.rossmoney.me

Travel archive built around a private image pipeline.

The travelling project is the site for my 2016 Southeast Asia trip, built as a separate gallery stack around the photos I brought back from Thailand, Laos, Vietnam, Cambodia, South Korea, Japan, Hong Kong, and Australia. PhotoPrism provides the source, PHP and nginx serve a privacy-preserving API and shell, and a client-side gallery renders the final experience.

What it is

A visual archive of the 2016 Southeast Asia journey.

The travelling project is a separate gallery stack built to revisit the trip cleanly, with PhotoPrism as the photo source and a privacy-preserving API layer around the images.

Story

Round trip through Asia

I went travelling round Southeast Asia in 2016, then continued through South Korea, Japan, Hong Kong, and Australia.

Place

Destinations and highlights

The gallery is organized around the places visited on the trip, making it easier to browse the route and the memories together.

Format

Photo-first archive

It is less a blog and more a private image mosaic, with supporting route notes and a lightweight travel narrative.

Audience

Personal reference

The site is mainly for revisiting the trip myself, while still being polished enough to share publicly.
